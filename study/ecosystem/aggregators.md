# Aggregators and the master catalog of Jev-alternative projects

Survey date: 2026-10-01. Jev = TypeSafe AI's hosted System One model (released 2026-09-15). "Claim" = what a source says about itself; "verified" = something I checked directly (API/README fetched). I verified GitHub metadata (stars, license, created date) with `gh`; I did NOT run any model.

## 1. The aggregators

### awesome-jev-tools (github.com/v-modal/awesome-jev-tools)
- What: curated GitHub awesome list of public projects built on (mostly *using*) hosted Jev. Created 2026-09-19; 736 stars on 2026-10-01 (verified via gh); last pushed 2026-10-01.
- Scale (verified from README): 13 categories, 221 projects total counting 50 "Related Practices / Discussions" entries. Per category: Classification & Routing 20, Verification & Guardrails 20, Scoring & Ranking 17, Agent Decisions 30, Data Labeling 2, Evaluation & Benchmarking 13, Calibration & Research 21, Infra/SDKs/Integrations 37, Game & Simulation 8, Finance & Trading 3, Compliance & Legal 1, Content Moderation 4.
- Quality stance: strict inclusion rules (must actually call Jev or be a concrete Jev-shaped artifact; excludes launch-hype commentary). Explicitly says "curation is not endorsement"; warns that bulk-submitted repos share an identical AGENTS.md/CLAUDE.md/STATE.md scaffold, land in 1-2 commits, and have more prose than code ("unproven; treat as leads"). Strips unverifiable claims.
- Usefulness: HIGH. Best-quality curated source for evaluations (13 entries) and "Calibration & Research" (21 open replicas). Skewed to apps using the hosted API; open-model coverage is only ~21 entries.

### madewithjev.com
- What: directory of "builds" (GitHub repos, X posts, YouTube, sites, resources). Launched 2026-09-15. Fetched summary: 749+ projects; top-level categories incl. Agents and browsers (170), SDKs and integrations (123), Benchmarks and evals (137), Open source (146), Games and real time (74), Routing (55), Social feeds (51), Tools and apps (50), Coding (40).
- Type breakdown shown on the open-source page: GitHub repos 330, X posts 433, YouTube 57, Sites 43, Resources 159 (these are site-wide totals; counts across pages are not mutually consistent).
- /categories/open-source ("Open source alternatives to Jev: 146 builds"): shows featured items with metrics: Laya (421M, 33 ms T4, 86.5 decisions/s), Kev (Qwen2.5-0.5B, ~160 ms), Reflex (154 stars shown), CUA-S1-FORMS (706K params), rizzo-flow (708 stars), AnyJev (861 stars), von (<15 ms), Julia 1 (144.3M), OpenJev (84.0% accuracy), Tev1 0.8B (~50 ms E2E). Note: the open-source category is a *mix* of replicas and open-source apps using Jev (e.g. Browser Use + Jev flight search 7 s/$0.004, DocJev, JevPilot, YouTube Sponsor Skipper, YC Indexor).
- Usefulness: MEDIUM-HIGH for discovery and as a popularity index; numbers are builder-reported. WebFetch only showed ~10 of the 146 entries, so the full list was not extracted.

### systemonemodels.org
- What: independent hub ("Not affiliated with TypeSafe AI or any model vendor"). 12 models, 732 examples, 18 use cases, 8 recipes, guides, glossary, a /compare/ section with no performance tables. No leaderboard.
- Models directory (12): Jev; Decider 1 (meraGPT, closed $0.03/MTok); Solar Decide (Upstage, closed $0.1); Tev1 (Together AI, Qwen3.5-4B, $0.042); Span-01 (Respan, $0.02); d1 (Liquid AI, free); OpenAI Decisions API (early access, GPT-6 Luna as listed); Mercury Decide (Inception, early access); Kev; Laya; CLM; GLiNER2.5-Decide (Fastino, 340M encoder, 38-167 ms). No benchmark numbers on the models page. (Hosted rival entries are not verified by me; the site lists them with "early access" status.)
- /examples/alternatives/: a table of ~44 rows with technique, base model, license, and what the project *claims* about calibration (e.g. Laya ECE 0.081 after temperature fitting; Von ECE 0.107 on a sealed test set; Verdict 2.0 ECE 0.0144/Brier 0.0636; Kev Brier 0.237; most replicas "no calibration claimed"; several say "not calibrated"). Also lists adjacent non-Jev tools (DSPy, Outlines, Instructor, GLiNER, SetFit, ModernBERT, MDLM). Notable for being the only aggregator that records calibration-claim status per project.
- Usefulness: HIGH for technique taxonomy and calibration-claim audit. Some internal inconsistency (Tev1 is "open weights, MIT code" on /alternatives/ but "Closed, Together AI hosted" on the models page).

### Broader GitHub sweep (my own, via gh search)
- Searching for Jev/Laya/System One/decision-model terms (created on/after 2026-09-10) returned ~880 distinct repos in my sample (sorted by stars per query, capped at 100 per query, so the long tail is under-sampled). Created-date distribution (repos matching jev|laya|system one|decision): 09-16: 11, 09-17: 45, 09-18: 73, 09-19: 87, 09-20: 110, 09-21: 110, 09-22: 127 (peak), 09-23: 82, 09-24: 55, then ~25-42/day through 09-30, 16 on 10-01 (partial day). So: explosive first week, peak ~one week after launch, decaying to roughly a quarter of peak.
- At least 36 additional "awesome-jev*" lists exist. Largest: yibie/awesome-jev 2,049 stars; heyjunpenn/awesome-jev 912 stars (claims "962 verified open-source projects"); logicrw/awesome-jev-projects 636; AnotiaWang/awesome-jev 593; kydlikebtc/awesome-jev 588 ("1207 public resources"); AbdelStark/awesome-typesafe-jev 551; OmniJev/awesome-jev-gallery 484; cobanov/awesome-jev 480; walidboulanouar/awesome-jev-use-cases 360 (74 demos, 150+ repos); yzfly/awesome-jev-zh; rupeshpoojary9/awesome-open-system-one; notsointresting/awesome-jev-family; yanng981/awesome-system-one. These duplicate each other heavily; the awesome-list itself is a meme-like cottage industry. Another peer list exists at Anil-matcha/awesome-jev-by-typesafe (referenced in v-modal).
- Academic: arXiv 2609.30216 "Jev in the Wild" (Ling, Xue, Ye) analyzed 2,170 public GitHub projects as of 2026-09-22 (fetched abstract). Findings: attribute judgment/scoring widely used; action selection, content filtering, model/tool selection vary by domain; public attention concentrates in routing and interface agents and does not track project counts.
- Reddit r/LLMDevs thread "I reviewed 287 open-source Jev projects" (cited by awesome-jev-tools; reddit.com not fetchable by my tools, so only the title/summary line is known: narrowed to ~20 that actually work).

## 2. Master catalog

How built: Tier A is hand-curated from systemonemodels.org /alternatives/ + models page, scriptbyai, dev.to, invidelabs, awesome-jev-tools "Calibration & Research", madewithjev, and GitHub, with claims copied from those sources (unverified by me). Tier B is machine-harvested from GitHub search (created on/after 2026-09-10, description matches replica/alternative/decision-model/compatible-server terms); technique, base model and role columns in Tier B are KEYWORD INFERENCES from the one-line description and are noisy (I sampled ~35 rows and estimated roughly 60% are genuine models/engines/servers; the rest are lists, benchmarks, wrappers, apps). Stars are as of 2026-10-01 via gh. All "open" labels refer to repo availability; actual weight openness is per the license column.

Technique classes: encoder-head | LLM-finetune | training-free-logit | diffusion | API-proxy | other.

## 4. Taxonomy observations
- Dominant technique classes (from systemonemodels table + Tier A): (1) small encoder + decision head (Laya, Von, Verdict, Julia, bekko, decima, OpenDecision) for ms-level latency; (2) LoRA/pointer-head fine-tunes of Qwen3.5 (Kev, Decider, Nimble, Lux, Reflex, Tev1); (3) training-free logit reading of a frozen LLM (SemIf, mini-jev, AnyJev, LitJev, ruling, rizzo-flow, openjev-sglang); (4) DiffusionGemma single-denoise-step (openjev, djev, tarski); (5) trained-from-scratch tiny models (jevlike, NanoJev, CUA-S1-FORMS 706K); (6) API proxies/emulators (notjev, OpenJev SiliconLabAI, iammrduncan/typesafe-ai-benchmark "imposter Jev").
- Laya is the gravitational center: 29.6k stars (NandhaKishorM/laya, Apache-2.0, created 2026-09-18), with dozens of ports (laya-mlx 6.7k, laya-coreml 1.5k, laya-js, laya-rust, laya.cpp, zlaya, laya-candle, laya-php, ruby-laya, laya-windows, ollaya 1.1k). Kev (jaredpalmer) 8.1k; SemIf 4.6k.
- Many repos are API-compatible by copying Jev's `POST /v1/systemone` wire format (Choice/Score/Noul), making swap-by-base-URL the de facto standard.
- Caveat on stars: star counts in this environment are inflated/unusual relative to age (e.g., 29k in 13 days); I report them as-is.
