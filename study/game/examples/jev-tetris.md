# JEV Tetris (thelau)

## Overview
A browser Tetris played by Jev. Code finds every reachable placement of the falling piece and describes each in an English sentence. Jev ranks the sentences, and the game plays the top-ranked placement. Its probabilities are drawn on the board before the piece drops.

## Relevance level
**Direct.** Hosted Jev through the TypeSafe API.

## Maturity / evidence
- Playable locally (`npm run dev`, or `dev:mock` without a key). Source with engine and UI tests. Created 2026-09-19; 3 stars.
- **Inspected:** README and `docs/findings.md`. **Not run:** it needs an API key and costs money.

## Game mechanic
The model is the player (agent control), but the decision is a ranking over descriptions generated by code, not a reading of the board.

## Decision inputs and outputs
- **Options:** one per reachable placement (moves, rotations, tucks and spins), described in prose, for example: "Traps no new space underneath. Clears one line. Flattens the surface out. The stack stays low. It goes at the centre, lying flat."
- **Questions:** five `choice` questions ("voices", e.g. sealed, unburied, clears, low, flat). The author's fixed weights blend their probabilities.
- **Consumption:** the code plays the blended argmax. Probabilities are rendered as cell brightness, and settled blocks are dimmed by confidence.

## Implementation / runtime
Node 22+, no dependencies. A server proxies requests, holds the key, and caps spend at 1,500 calls or $1. Every call is logged to `runs/*.jsonl` before its answer is used.

## Attributed results (author, `docs/findings.md`; 3 seeds, capped)
| Player | Pieces | Lines |
|---|---|---|
| Random | 20 · 21 · 22 | 0 · 0 · 0 |
| Jev, probabilities shuffled across options | 24 · 18 · 18 | 0 · 0 · 0 |
| Jev as built | 83 · 300 · 90 | 23 · 115 · 23 |
| 23-line keyword regex over the same sentences | 300 · 210 · 300 | 118 · 73 · 118 |
| El-Tetris heuristic | 300 · 300 · 300 | 118 · 118 · 116 |

- Median latency is about 380 ms per decision (hosted).
- The author's own caveats:
  - The configuration was tuned on these three seeds.
  - About three quarters of the score is attributable to the hand-fitted weights; with equal weights the mean drops from about 52 to about 11.7 lines.
  - The blended pick equals one voice's argmax 91% of the time.
- The shuffle control shows that the model's ranking does carry the game.

## Possible jeff adaptation (inference)
jeff could rank the same sentences (each placement is one option, within the 255-option limit). However, the keyword baseline already beats Jev here. When the code writes options that encode the answer, a classifier adds little. This pattern is useful for a jeff experiment only as a **harness check**: deterministic options, a measurable score, and shuffle and keyword controls.

## Limitations
- Three seeds only.
- The configuration was tuned in-sample.
- Latency is acceptable only because Tetris can wait for a decision at each spawn.
